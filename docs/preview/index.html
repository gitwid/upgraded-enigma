  • ☥ Breath — Arrive. Grounding, and one factual line about the gap since your last capture. It reads nothing into it.

Protocol 0.3 — capture at event speed

The protocol has always recorded recall latency: an admission that memory decays between an event and the writing of it. The four-stage journey widens that gap. Record closes it — one blurt, stored in an unsorted channel rather than filed into a layer it may not belong in. Sorting it later is an annotation, never an edit.

Adding a field to hashed content is exactly the change that silently invalidates history. It doesn't here, because content is rebuilt from each capture's own recorded version. Seed a capture written the way the previous release wrote them and watch it keep verifying beside 0.3 ones:
